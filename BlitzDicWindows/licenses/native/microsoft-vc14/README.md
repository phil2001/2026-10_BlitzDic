# Microsoft Visual C++ V14 end-user terms

The original Microsoft DOCX is retained without modification. Its source URL
and SHA-256 are recorded in `provenance.json`. `Runtime-LICENSE.txt` contains
its text runs in paragraph order, with blank lines between paragraphs.
Word formatting and automatic list numbering are omitted in this text copy.

The Windows build verifies both file hashes before generating the installer
license page. That page identifies the scope of the MIT and Microsoft terms
separately. The same generated text is installed under
`resources/licenses/dependencies/Installer-LICENSE.txt`. The original document
remains available in the native license folder.

These terms concern the Microsoft runtime components, not the BlitzDic source,
speech models or other third-party libraries. The publisher's right to ship
the runtime comes from its own applicable Visual Studio license, not from
this end-user text. See [the publisher assessment](../MICROSOFT_RUNTIME.md).
